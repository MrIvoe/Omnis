# OpenSubsonicPlugin

Connects to any OpenSubsonic-compatible media server — Navidrome, Airsonic, the original Subsonic, and anything else implementing the same REST API — via that public protocol.

## Where it lives

`Omnis-Plugins/lib/opensubsonic_plugin.dart`

- [[IOnlineSearchProvider]]

- [[31 - OpenSubsonic]]
- [[32 - Navidrome]] (Navidrome speaks the OpenSubsonic protocol)
