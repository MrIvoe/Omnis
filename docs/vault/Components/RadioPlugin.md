# RadioPlugin

A bundled Internet Radio plugin: search and browse live streaming stations via the [Radio Browser](https://www.radio-browser.info) community directory — a free, keyless public API (tens of thousands of real Icecast/Shoutcast stations), unlike `MetadataEnrichmentPlugin` which needs user-supplied API keys for most of its sources.

## Where it lives

`Omnis-Plugins/lib/radio_plugin.dart`

- [[50 - Automation]] (scheduled radio — a saved custom station)
