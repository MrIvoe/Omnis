# YoutubePlaybackPlugin

Plays a YouTube video's real audio+video through YouTube's own official embedded IFrame player — the only ToS-compliant way for a third-party app to play YouTube content.

## Where it lives

`Omnis-Plugins/lib/youtube_playback_plugin.dart`
