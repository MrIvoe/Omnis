# ArtistImagePlugin

Looks up a real artist photo via Deezer's public search API (`api.deezer.com/search/artist`) — free, unauthenticated, no account or key needed, the same "no credential required" tier `MetadataEnrichmentPlugin`'s MusicBrainz lookup sits at.

## Where it lives

`Omnis-Plugins/lib/artist_image_plugin.dart`

## Implements

- [[IArtistImageProvider]]

## Serves

Not named by any of the 50 tracked features — supplies artist photos for artist detail pages/tiles, a supporting visual feature not separately tracked in this plan.
