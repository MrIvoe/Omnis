# BluetoothPlaybackPlugin

Detects a Bluetooth audio device (speaker, car stereo, headphones) connecting or disconnecting, and offers one-tap "quick play" — an entire library shuffle, a mood, or a saved playlist — for exactly the "just got in the car, want music going" moment this was built for.
