# Documentation directory

Everything technical about Omnis, in one place. If you just want to
know what Omnis *is*, read the [root README](../README.md) instead —
this folder is the "how it actually works" layer underneath it.

| Doc | What's in it |
| --- | --- |
| [FEATURES.md](FEATURES.md) | The full feature list, by category |
| [ARCHITECTURE.md](ARCHITECTURE.md) | How the micro-kernel is put together and why: the Core/plugin split, `ServiceRegistry`/`EventBus`, `PluginContext`/`PluginStorage`, player layouts, and an honest "what's real vs. approximated" breakdown |
| [PLUGIN_GUIDE.md](PLUGIN_GUIDE.md) | How to build a plugin, bundled or downloadable, with a complete working example |
| [PLUGIN_SECURITY.md](PLUGIN_SECURITY.md) | What a downloaded plugin can and can't do — written for anyone deciding whether to paste a GitHub URL in |
| [COMMUNITY_PLUGINS.md](COMMUNITY_PLUGINS.md) | Curated list of downloadable community plugins, and how to get yours added |
| [BUILDING.md](BUILDING.md) | Prerequisites, running, testing, building release artifacts, signing |
| [RELEASING.md](RELEASING.md) | How a version gets from a commit to a downloadable beta on the Releases page |
| [MANUAL_QA.md](MANUAL_QA.md) | The handful of things that can only be verified on real hardware |
| [OMNIS_2_0_STATUS.md](OMNIS_2_0_STATUS.md) | Phase-by-phase build progress and the completion-% methodology |

Also see the [wiki](https://github.com/MrIvoe/Omnis/wiki) for a
long-form guided walkthrough, and
[CONTRIBUTING.md](../CONTRIBUTING.md) for the contribution workflow.
